## 2. 修改了什么

### 学术准确性（12 项，最严重一类）
修复了论文内部矛盾——第四节（六）已把预测结论降级为"历史回顾性模型筛选与验证"，但摘要、第四章、第九章、第十章仍保留旧口径表述：

| 位置 | 原文 | 改后 |
|---|---|---|
| 摘要·结论 | "**可观**的价格可预测性" | "**有限**的价格可预测性" |
| §4.3 | 该偏差使精度被"**轻微**高估" | 删除"轻微"，指向 §4.6 的量化结果 |
| §9.6 | 精度"可能被轻微高估" | "低估幅度可观（平均相对改善由 +18.9% 变为 −4.0%）" |
| §10.1-2 | "在严格滚动样本外条件下……7 种优于基线" | 同时给出同折口径（7/10、+2.7%—24.0%）与前向口径（9/20、−3.99%） |
| 摘要·结果 | 只报 7/10 | 补入前向验证结果与"排除调参模型 −7.47%" |
| §7.2 | 未提示偏差传导 | 补"该口径下超额估计应视为上界" |

### 结构与正式性（8 项）
- **删除全部内部修订史**：4 处"早期版本曾……已作废""本文修复后……"
- **删除写作纪律外泄**："本文明确不采用的表述：不得写……"
- **删除自我评价用语**：小标题"（本文最重要的诚实结论）"、"不会自欺"、"这一负面结果被完整保留"
- **删除附录中的开发记录**：附表 2「方法核验与缺陷修复摘要」整表删除
- **补全空壳附录**：附录 2 补入实际超参数与策略权重（取自代码，可核验）
- **修正表号顺序**：前向验证表由"表 15"改为"表 6"，其后顺延；排序口径对照表保持"表 16"
- **修正附录跳号**：附录 1—3
- 合并第三章重复的"未独立复算"说明

### 语言（9 类）
加粗标记 **394 → 40**；摘要"其一…其六"改为线索式行文；"必须强调/需要说明"类提醒语 8 → 5（保留者为事实性限定）；删除 6 处空泛过渡句；概念重复定义（市场机会收益≠利润、HRI≠跟风概率、未观测农户行为）各由 4—5 次压到 2 次。

### 论证（第七章改动最大）
- §7.2 对"密集切点显著、不重叠切点不显著"给出**三种并列解释**，并标明哪一种是直接证据、哪些属推测（原稿只有一句技术断言）
- §4.4 补入"为何 ElasticNet 系列胜出、CatBoost 全部落选"的解释
- §8 稳健性明确区分"有直接证据"与"属推测"
- §9.2 三点解释分级；政策建议改为"谁用、何时用、解决什么、限制在哪"
