# PORTFOLIO_MODEL_REPORT — 多作物组合优化

## 1. 模型假设（写死）

- 土地可分割；每个面积单元一个生产季只种一种作物（**不做复种**，§53）；
- 组合仅同一规划季内；
- 面积不影响价格（无农户级市场冲击模型）；
- 组合风险 = **面积加权平均 + 集中度惩罚(HHI) + 相关性惩罚（历史收益相关）**，不强行套 Markowitz。
