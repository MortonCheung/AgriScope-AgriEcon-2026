# 06 EVENT STUDY — 全历史极端天气的平均市场响应（STEP 12）

> 窗口 **T-14 ~ T+21**（T0=事件簇开始日）；统计单元 = **复合事件簇**（§三十一：间隔 ≤3 天的事件合并）；响应 = 去季节化稳健 z − 事件前窗均值（§三十：相对事件前正常状态）。

> 证据等级：Level B（统计关联）。事件=算法派生（ERA5 阈值识别），与官方通报严格分开（§二十九）；官方事件仅 STEP 13 作定性佐证。

## 2. 方法

| 环节 | 实现 |
|---|---|
| 事件相对化 | z_rel = z(方法B 去季节化稳健 z) − mean(z, T-14..T-1)；前窗观测 <5 的品种剔除 |
| 平均曲线 | 簇×品种单元在每 offset 上取均值（图示重点 T-7..T+14） |
| CI | 簇级 Bootstrap，B=1000，重抽簇整簇替换，2.5/97.5 百分位 |
| 零分布 | 安慰剂事件 500 个：伪 T0 采样自与任何真实事件窗不重叠的日期 |
| 事后统计量 | mean(z_rel, T+1..T+14)，双侧经验 p |

## 3. 主结果：平均事件响应（雨事件簇）

| 响应 | 前窗均值(z_rel, T-14..T-1) | 事后 T+1..T+14 | 95% Bootstrap CI | 安慰剂 p | 事后谷底(T+1..T+14, z) | CI 不含 0 的 offset 数(T-7..T+14) |
|---|---|---|---|---|---|---|
| 价格 | +0.000 | +0.017 | [-0.405, +0.451] | 0.942 | T+2, -0.202 | 0/22 |
| 成交量 | +0.000 | +0.075 | [-0.079, +0.340] | 0.709 | T+6, -0.180 | 1/22 |

- 判定：事后均值 CI 含 0 且安慰剂 p>0.05 → 该响应在事件口径下记`NOT SUPPORTED BY CURRENT DATA`；
- 曲线逐 offset 的 CI 不含 0 的格子仅作探索性描述（多重比较未校正），正式结论以上一行事后窗统计为准。

## 8. 本节结论（Level B）

- 雨事件 → 价格：事后均值 +0.017 [-0.405, +0.451]，安慰剂 p=0.942 → `NOT SUPPORTED BY CURRENT DATA`
- 雨事件 → 成交量：事后均值 +0.075 [-0.079, +0.340]，安慰剂 p=0.709 → `NOT SUPPORTED BY CURRENT DATA`
- 该结论与 STEP 10（日度滞后）、STEP 11（非线性/临界点）共享同一功效约束（AR(1) 高、事件数少）；事件口径把「极端日」而非「连续日值」作为处理，是对前两步的重要补充，但同样不构成因果识别。
