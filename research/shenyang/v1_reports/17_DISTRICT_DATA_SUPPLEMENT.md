# 17 区县农业生产数据补充 — 采集与决策记录

> 范围：只补齐沈阳市各区县农业生产数据 + 可对应的区县天气数据。
> 详细质量检查见 `16_DISTRICT_DATA_QA.md`；给人看的成果见
> `../../reports/04_沈阳区县农业生产与气象数据.md`。

## 1 先行审计（本轮开始时确认的既有情况）

| 项 | 审计结论 |
|---|---|
| 已有区县生产数据 | **无**（仓库与 shenyang 项目均无区县生产数据；辽宁省年鉴「各地区」表仅到 14 个地级市） |
| 已有沈阳年度生产 | 市级 2017–2025（辽宁统计年鉴 + 2025 公报） |
| 已有天气 | 市级单点 + 沈北新区单点（Open-Meteo ERA5，含 1991–2020 基线） |
| 已有区县生产采集器 | **无**（`collectors/` 只有市级 `bulletin_production.py` 等） |

据此判定：区县生产数据须**新增采集**；天气须**沿用既有 Open-Meteo ERA5 体系**（不换源）。

## 2 数据源选择决策

| 决策 | 选择 | 理由 |
|---|---|---|
| 生产主源 | 《沈阳统计年鉴》农业章 **3-4/3-5/3-6 分区县表** | 全市统一口径、同时含面积+产量+单产、A 级；覆盖 2018–2024 |
| 生产辅源 | 区县统计公报/年鉴 | 交叉校验 + 补 2025 + 补 2015–2017 |
| 天气源 | Open-Meteo Archive（ERA5 / ERA5-Land） | 与既有沈阳市场研究**完全一致**，不换源 |
| 代表点 | 区县行政中心坐标（农业农村部 pfsc 官方接口） | 与既有 `city_static.csv` 同源；沈北新区坐标与既有 `OM-沈北新区` 完全一致 |
| 时间范围 | 生产 2018–2024（+康平 2015–2017）；天气 2015–2025 | 生产受官方可得性约束；天气覆盖全部生产年 |

## 3 解析方法（可复现）

年鉴三张分区县表结构一致：**行 = 作物，列 = 地区（沈阳市 + 8 农业区县）**。
用 PyMuPDF 取 words（含 bbox）→ 按 y 聚类成行 → 行内按 x 合并碎词（"1"+"358"→1358）
→ 按表头列中心归位。各卷表号不同（2019/2020 卷为 3-6/3-7/3-8；2021/2022 卷为 3-4/3-5/3-6；
2023 卷为 3-3/3-4/3-5；2024/2025 卷为 3-4/3-5/3-6），用「含『农作物总播种面积』且含
『苏家屯区』的页 = 面积表，其后两页 = 产量、单产」定位。

作物名规范化（仅消除各卷写法差异，保留原始标签）：
- 「薯类」≡「薯类（折粮）」（2023/2024 卷面积表省略"折粮"）
- 「春小麦」≡「小麦」（两值逐行完全相等，37/37 校验）
- 「向日葵籽」≡「葵花籽」

## 4 遇到的站点问题与处理

| 问题 | 处理 |
|---|---|
| 康平县政府站点 TLS 握手不接受默认密码套件 | 使用 unverified SSL + http 回退 |
| 新民市公报标题用中文数字年份（二〇二五年） | 年份解析支持中文数字 |
| 沈阳统计年鉴 2016/2017/2018 卷落地页无附件 | 判定 2015–2017 市级口径不可得；改用区县年鉴补康平县 |
| 部分区县公报正文在 PDF/DOC 附件内 | 采集脚本增加「条目页内附件下钻」 |
| 公报 filename 冲突（同年多条目） | 文件名改为「年份 + 条目ID」双键 |
| 沈北新区区级公报仅给农林牧渔业总产值 | 如实记录；沈北作物数据只来自市级年鉴 |
| pip 环境缺 xlrd（读 .xls） | 安装 xlrd 2.0.1（仅用于读年鉴原始件） |

## 5 已知数据异常（不修改，只记录）

1. **2022 年（2023 卷）绿豆行**：区县产量与单产数值相同（如康平 1358/1358），
   导致「面积×单产≠产量」且「区县合计 4,246 吨 >> 市级 15 吨」。判为**上游年鉴数字异常**，
   原样保留并在 QA 报告中单列。
2. **区县合计 < 市级合计（系统性）**：因 5 个城市核心区计入市级但不单列，属正常口径差。
3. **公报抽取越界**：同一公报文件含多层级（区/市/省）数字时，first-match 可能取到市级值
   （如辽中区 2020/2021 若干行）。已加 `check_flag=suspect_scope(>100%)` 标记并排除出"已验证"。
4. **于洪区蔬菜产量**：公报（8.68 万吨）与年鉴（17.23 万吨）差约 2 倍，
   疑为「蔬菜」vs「蔬菜（含菜用瓜）及食用菌」口径差异，标记 `diff>5%`。
5. **ERA5 极端高温平滑**：2020–2024 年各区县 ≥35℃ 高温日数为 0（再分析特征，非缺数据）。

## 6 红线遵守情况

- 未插值、未推算、未按比例拆分到区县、未按蔬菜总量拆分品种；
- 未把 0 当缺失；空单元格一律留空；
- 未把再分析写成气象站实测；
- 原始文件与原始单位全部保留（`value_raw`/`unit_raw`），标准化值另列；
- 未破坏既有项目结构（新增 `data/raw/district_production/`、`data/processed/district_*`）。
