# DECISION LOG — 沈阳农业气象风险研究（§六十五：研究全过程可审查的研究理由与决策依据）

> 用途：记录每个阶段的「研究问题 / 为什么做 / 使用数据 / 方法 / 主要假设 / 发现 / 异常 / 是否继续 / 下一步」。
> 配套：`outputs/results_registry.csv`（结果血缘）、`reports/BLOCKERS.md`（数据阻断）、各阶段 `reports/0X_*.md`。

## 0 全局决策

| 项 | 决策 | 理由 |
|---|---|---|
| 研究城市 | 仅沈阳 | 任务书限定；禁止省代市、沈北代市 |
| 研究对象 | 10 种核心批发蔬菜 | 任务书 §四 |
| 证据分级 | A/B/C/D | 因果措辞保守（§三十八、§五十五） |
| 成交量单位 | `unknown`，禁止写吨 | 官方接口未标注单位 |
| 去季节化主方法 | 留一年法（LOO）历史同期中位数 | 无未来泄漏（§二十一）；STL 仅对照 |
| 预测时间切分 | train ≤2024 / valid 2025 / test 2026 | §五十一 禁止 shuffle；Rolling Origin 扩张窗 |
| 特征口径 | F_wx（仅天气）/ F_lag（+自回归，主）/ F_now | 隔离「持续性 vs 天气」贡献 |
| 反事实门控 | World0 R² ≥ 0.10 | §五十六：模型无法复现现实则禁止外推 |

## 1 按阶段记录

### STEP 01-03 数据冻结与项目结构
- 研究问题：数据源是否真实、可重建？ 为什么做：一切结论依赖可审计数据。
- 使用数据：liaoning-agri-risk 仓库（只读）。 方法：文件清单 + SHA256 快照 + 数据字典。
- 发现：仓库完整；市场 2020-2026、天气 2021-2026、事件 20 起。
- 异常：官方 30 年 vpd/土壤基线缺失（→ BLOCKERS）。
- 是否继续：是。下一步：建面板。

### STEP 04-06 面板与 QA
- 研究问题：日度面板质量如何？ 方法：字段核对、缺失/重复/极端值、天气-市场对齐。
- 发现：14,100 行 10 品种；`is_weekend` 全 0（仅交易日）；目标异常无缺失。
- 异常：2020 年无气象（研究窗取 2021 起交集）。
- 是否继续：是。下一步：描述与去季节化。

### STEP 07-09 描述 / 季节 / 异常
- 发现：量价强季节性与强持续性；价格异常幅度品种间差异大。
- 异常：成交量含 0（与极端异常日重合）——**不把 0 当缺失**（红线）。
- 是否继续：是。

### STEP 10-11 滞后与非线性
- 方法：逐品种 HAC(14) 分布滞后 + GAM 非线性 Wald + 分段断点 + FDR。
- 发现：天气→量价无 FDR 显著项；非线性 family min FDR 价格 0.286 / 量 0.144。
- 是否继续：是（转事件口径复核）。下一步：Event Study。

### STEP 12-13 事件研究与 2026-07 案例
- 方法：事件簇（重叠≤3 天合并）+ 事件相对化稳健 z + 500 次 placebo。
- 发现：雨事件价格 post +0.017 / 量 +0.075，placebo 不可分辨；2026-07 最强暴雨（173.9mm）价格符合历史规律、成交量边缘偏离（placebo p=0.154）。
- 异常：案例单事件、功效有限。
- 是否继续：是。下一步：Milestone 1 汇总。

### STEP 15-17 传导机制
- 方法：两阶段 HAC/聚类回归 + 中介块 Bootstrap（B=500）。
- 发现：weather→volume ≈0；volume→price 同日系数小；间接效应 0/10 排除 0。
- **链式传导在该尺度上不成立（Level B）**。
- 是否继续：是（预测模型验证持续性假说）。下一步：STEP 23。

### STEP 18-22 异质性 / 指纹 / 韧性 / 物候 / 生产
- 发现：品种敏感度全不显著；黄瓜价格指纹独立成簇（描述性）；韧性恢复天数 2-3 天量级；
  物候交互 `NOT SUPPORTED`；蔬菜年度数据 2020-2024 缺失（BLOCKERS）。
- 是否继续：是（模型反事实仍可做，但预期阴性）。

### STEP 23-24 预测与解释
- 方法：时间切分 + Rolling Origin + 无泄漏 Prep（median impute + scaler 仅 fit 训练集）。
- 发现：**高 R²=0.94 来自持续性**（lag1 自相关 0.967/0.899）；F_wx 天气口径 R²<0；
  SHAP 天气特征合计 <5%；结论不得写「天气驱动价格」。
- 异常：ROLL origin 实际 3 折 < 配置 4 折（告警）；strict 口径 2021 参照年仅 1 年。
- 是否继续：是（反事实仍按 §五十六 先做门控）。

### STEP 25-26 反事实平行世界
- 方法：递归链（天气→量→价）+ 方法A/B 替换 + 严重度 + 缓冲 + 配对残差 Bootstrap。
- 发现：**World0 门控未过**（price R²=-0.47、volume R²=0.08）→ 缺口仅作 Level D 演示；
  价格缺口 -0.36 z（方向：灾害→价格↑）；缓冲对价格影响≈0。
- 异常：门控未过是"停止外推"的既定规则触发，不是失败。
- 是否继续：是（稳健性判定后再进终稿）。

### STEP 27 稳健性
- 方法：基线方法 / 事件窗 / 模型族 / 天气指标 / placebo / Bootstrap。
- 发现：价格缺口方向跨模型 Stable；成交量缺口方向 Sensitive；placebo 不可分辨。
- 是否继续：是。下一步：终稿。
