## 0 研究总目标

以**现有真实数据**为基础，重新设计、重新计算、重新审查 沈阳市的农业气象研究，回答：

- **生产端**：沈阳各区县种什么、种多少、产多少；天气变化与单产/总产量是否有关？
- **市场端**：沈阳主要蔬菜批发市场的价格与成交量如何随时间变化；气象条件与市场异常是否有关；极端天气事件下市场如何响应？
- **两端关系**：两组证据能否相互支持？

本计划**不新增研究**：正式成果固定为 **8 篇专题（A01–A08）+ 1 篇综合（A09）**。
内部可以存在数十个两两关系，但人类最终只阅读这 9 篇。

## 3 八项专题研究（A01–A08）

### A01 沈阳市主要蔬菜批发市场的时间结构与季节性特征
- **问题**：价格怎样随时间变化？成交量怎样随时间变化？是否存在季节性？是否存在长期趋势？
- **数据**：10 种蔬菜日度价格与成交量，2021–2026。
- **方法（至少重新计算）**：①月度中位数；②月度分布；③季节指数；④年度水平；⑤趋势；⑥STL（**仅作描述**）；⑦HAC 趋势 CI。
- **写作纪律**：不得把"价格承担供需调节功能"这类**机制性语言写进结果**；最多写"价格季节波动明显，而成交量季节波动相对有限"，原因放讨论。
- **假设类型**：descriptive。

### A02 气象条件与沈阳市主要蔬菜批发市场日度响应
- **问题**：温度、降水、湿度、风、VPD、辐射、ET0、土壤水分等，与价格异常、成交量异常是否存在**稳定关系**？
- **预处理**：价格/成交量必须先处理季节性、趋势、**强时间持续性**；优先沿用无未来泄漏的历史同期基线，但**必须重新验证其合理性**。
- **主模型（不得只做 `price ~ weather`）**：

  ```
  y_t = α + φ·y_(t-1) + β·weather_t + calendar controls + ε_t
  ```

  理由：价格异常存在极强持续性（AR(1)≈0.97）；若不控制，会把共同慢变趋势误认为天气作用。
- **暴露变量**：正式主分析**只选农学上可解释的核心变量**——precipitation / temperature / VPD(或 humidity) / wind / soil moisture。
  pressure / cloud / radiation / dew point / ET0 放**补充分析**。
  **禁止**十几个变量同等重要地扫一遍后挑最好看的。
- **必须报告**：effect size、95% CI、raw p、FDR p、N、**AR(1)**、标准化单位。重点是"效应有多大"，不是"p 是否 <0.05"。
- **稳健性**：仅天气滞后口径（无自回归）与含自回归口径对照；安慰剂。
- **假设类型**：confirmatory。

### A03 气象影响的滞后、累积与非线性特征
（原 Lag / precipitation windows / threshold 的正式重做）
- **Lag**：**不盲目搜索几十个 lag 后选峰值**。主分析采用**预定义窗口**：`0日 / 1–3日 / 4–7日 / 8–14日`。0–30 日扫描**仅作补充诊断**。
- **累积降水**：正式比较 `1 / 3 / 7 / 14 日`；必须区分**累积效应**与**标准化尺度变化**。
- **非线性**：使用 GAM / spline，但**只有在整体非线性有证据时才讨论"阈值"**。
  **禁止**："GAM 没显著 → 继续找 breakpoint → 找到一个漂亮数字 → 称其阈值。"
  阈值必须同时具有：统计支持、样本支持、稳健性、可解释性。
- **假设类型**：confirmatory。

### A04 极端天气事件下沈阳市蔬菜批发市场响应及 2026 年强降雨案例
- **两套事件必须分开**：官方事件（气象部门/政府/官方新闻） vs 算法事件（ERA5 指标识别）。
- **Event Study**：重新建立 clean event；检查**事件重叠、前事件污染、后续再次冲击**。
  主窗口 `T-14 → T+14`；基准期建议 `T-14 → T-4`（避免临近天气变化）。
- **Placebo**：随机日期**不能随便抽**，必须尽量匹配**年份、季节、星期结构**，且为非事件日期；**至少 500 次**。
- **2026 案例**：单独作 case study，文章必须清楚回答：①这次天气有多极端？②与历史事件相比排第几？③价格怎样变化？④成交量怎样变化？⑤是否超出普通日期波动范围？⑥是否超出历史极端事件范围？
  **不要先写"暴雨没有影响"，先展示证据。**
- **假设类型**：confirmatory（+ 案例为 descriptive）。

### A05 沈阳市不同蔬菜的气象响应差异与市场恢复特征
- **问题**：同一种天气冲击下，哪些品种响应更大？哪些更快？哪些恢复更慢？
- **异质性**：**不得**单纯比较"某菜 p<0.05 / 某菜 p>0.05"（这不能证明两种菜不同）。应使用 **crop × weather 交互项**或直接比较**系数差异**。
- **恢复**：定义**必须提前固定**（如"异常值重新进入事件前基线区间并连续维持若干日"）。
  同时处理 **42 天仍未恢复** 与 **后续新事件导致恢复观察被截断**（right censoring）。
  可使用 Kaplan–Meier 描述与 event-cluster bootstrap；**不得制造没有统计依据的"韧性分数"**。
- **假设类型**：exploratory（明确标注，不得伪装成验证性）。

### A06 沈阳市蔬菜市场量价关系风险传导与天气信息预测增量
三个高度相关问题放在一起：
- **6.1 成交量与价格**：重新分析 `volume_t ↔ price_t`、`volume_(t-k) → price_t`、`price_(t-k) → volume_t`；**必须控制自身滞后、季节性、时间趋势**。
- **6.2 天气→成交量→价格**：**只有两个步骤都有证据，才讨论 mediation**。若 `weather → volume` 本身都不成立，则**不应再写"存在供应传导"**；正式结论可以是"当前数据未提供支持该链条的统计证据"。
- **6.3 天气有没有预测价值**：建立真正的 baseline——
  - **Baseline**：只使用历史价格、历史成交量、日历变量。
  - **Weather model**：Baseline + weather。
  - 比较 RMSE / MAE / R² / ΔRMSE / ΔR²；**必须 Rolling Origin**，不能随机 train/test split。
  - 只有 **weather model 相对于 baseline 的增量**才叫"天气预测价值"。
  - SHAP / ALE **只解释模型**，禁止写成因果。
- **假设类型**：confirmatory（6.1/6.3）+ descriptive（6.2 的链式判定）。

### A07 沈阳市农业生产的区县格局与作物结构（2018–2024）
- **主样本**：8 个农业区县；**主时间 2018–2024**。2015–2017 仅康平 → 只放补充材料，**不得混进平衡主面板**。2025 不进主研究。
- **核心作物/类别**：首先使用**面积、产量、单产三者都完整覆盖 `7年 × 8区县`** 的类别（粮食、谷物、稻谷、玉米、豆类、大豆、蔬菜及食用菌、瓜果、甜瓜 等）。
- **层级嵌套警告**：`粮食 ⊃ 谷物 ⊃ {稻谷, 玉米}`；**禁止把这些类别直接相加**。
- **研究内容**：①各区县农业结构；②播种面积；③产量；④单产；⑤年际变化；⑥作物结构差异。**不要为了复杂而建模**——本篇首先是**农业生产结构研究**。
- **假设类型**：descriptive。

### A08 气象条件与沈阳市农业单产变化的区县面板研究（本轮最重要的新实验）
- **核心问题**：天气变化与单产、总产量是否存在关系？
- **Primary outcome = 单产（yield）**。理由：`总产量 = 面积 × 单产`；若只研究总产量，会把**种植面积变化误认为天气影响**。
- **Secondary outcome = 总产量**。
- **播种面积**：主要作结构变量 / 控制变量 / 描述变量。**不要轻易写"当年夏季天气导致当年播种面积变化"**（播种决定通常发生在天气冲击之前）。
- **天气变量设计（§9）**：**不能把 34 个年度天气指标全部塞进模型**。首先确定具有农业意义的**核心暴露**：
  - 温度：生长季平均温度；Tmax 异常；热量异常
  - 降水：生长季累计降水；最大 1 日；最大 3 日；强降水频率
  - 水分：土壤水分；ET0；VPD
  模型必须保持简单：单个作物只有 `8 区县 × 7 年 = 56 observations`，**不允许几十个解释变量**；天气变量**一次只进入 1–2 个核心变量**。
- **ERA5 高温指标问题（§10）**：现有数据已发现 **2020–2024 年 ≥35℃ 日数 = 0**（ERA5 网格平滑造成的现实特征）。
  因此**不要强行研究"35℃ 高温日"**；主研究改用 **Tmax anomaly / 同区县历史 percentile / 标准化温度异常**。
  **必须明确 ERA5 是网格再分析，不是站点最高温。**
- **核心模型（§11）**：逐核心作物单独研究

  ```
  Yield_d,t = β · Weather_d,t + District FE + Year FE + ε_d,t
  ```

  其中 `d = district`、`t = year`。优先 `log(yield)` 或标准化 yield anomaly。
- **小样本推断（§12）**：只有 **8 个 district clusters**，普通 cluster SE 可能不可靠，至少做：
  ① district-cluster robust SE；② leave-one-district-out；③ leave-one-year-out；④ wild cluster bootstrap（如环境允许）。
  **若无法可靠做 wild bootstrap，直接说明；不得假装 8 clusters 足够精确。**
- **多重检验（§13）**：若 `9 crops × 4 weather exposures` 即已有 36 个检验，必须：预先定义 family；BH-FDR；**同时报告 raw p 与 q**。
  **不能从 36 个里挑 3 个 p<0.05 写成发现。**
- **假设类型**：confirmatory。

## 6 写作风格与禁止用语（§19–§22）

- 正式学术中文。结果段只写"**数据显示什么**"；讨论段才写"**可能意味着什么**"。
- **禁止**（除非证据确实支持）：`我们发现了一个非常有意思的现象`、`值得注意的是`、`令人惊讶的是`、`深度揭示`、`赋能`、`有力证明`、`充分体现`、`说明市场具有强大韧性`。
- **每一个重要结论必须有数字**。
  - ✗ "降雨影响较弱。" → ✓ "在预设模型中，10 种蔬菜均未在 FDR 校正后获得稳定的降水效应；效应估计及 95% 置信区间见表 X。"
  - ✗ "市场具有明显季节性。" → ✓ "价格季节强度中位数为 X，其中 Y 种超过预设阈值。"
- **阴性结果必须正常写**（§21）：正式论文允许"未得到支持"，并解释 effect size、CI、power、sample limitation。"没有证据"本身就是结果。
- 若一段文字删掉所有形容词后没有数字、证据或逻辑价值 → **删除**。

## 7 图表原则（§27–§28）

- **一张图只回答一个明确问题**；禁止为"显得研究多"而画几十张图；每篇主文章建议 **2–5 张核心图**。
- 图必须：标题描述研究问题；坐标有单位；caption 说明 N 与数据范围；必要时显示 CI；不用夸张配色；不用伪 3D。
- 文章中的表必须**能独立阅读**，至少给：变量、estimate、CI、N、q value、interpretation。**不得把原始 dataframe 直接导进正文**。
- 所有过程诊断图留在 `workspace/research_v2/results/`，**不进入人类报告**。
