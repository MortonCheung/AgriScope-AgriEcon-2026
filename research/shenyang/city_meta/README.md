# 沈阳农业气象数据分析

这是 AgriScope 项目中的**沈阳单城市数据分析工程**。

本目录只负责：

- 沈阳数据；
- 沈阳数据分析；
- 沈阳研究结果。

前端、比赛交付和其他城市项目不放在这里。

---

## 目录

### `reports/`

**给人看的。**

想了解沈阳：

- 有什么数据；
- 做了什么研究；
- 得到了什么结果；
- 有哪些图表；

直接进入这里。

### `workspace/`

**分析工程工作区。**

包括：

- 数据；
- Python 分析代码；
- 配置；
- 全部分析输出；
- 模型；
- 过程报告；
- 日志；
- 运行脚本。

日常阅读不需要进入这里。

---

## 使用原则

看研究：

`reports/`

继续做分析：

`workspace/`
