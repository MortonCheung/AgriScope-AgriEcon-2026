# MARKET_EVENT_STUDY_PREREGISTRATION.md（R16 / §七十七~八十三）

> 目的：Data Agent 在抓价格/成交量；**先定研究设计**，数据到达即可执行。状态：**PREREGISTERED**。

## 1. 研究问题（不是“下雨后价格涨没涨”）
> 2026 极端事件之后，**玉米市场价格 / 成交量**是否相对**正常季节轨迹**出现异常变化？

## 2. 必须控制季节性（§七十九）
玉米市场天然存在收获季/新粮上市/库存变化。
**禁止**：`7月价格 vs 8月价格` 直接归因于暴雨。

**正确结构**：
```
abnormal_price(t)  = price_2026(t) − seasonal_expected(t | 2021–2025 同期)
abnormal_volume(t) = volume_2026(t) − seasonal_expected(t | 2021–2025 同期)
```

## 3. 事件窗口（预注册）
```
T−4 weeks  →  T+8 / T+12 weeks    （T = 2026-07-13）
```
数据不足时可调整，但**必须说明原因**。

## 4. 分析方法候选（按数据决定，**不预先强制 DID**）
`Event Study` / `Interrupted Time Series` / `Seasonal anomaly` / `Distributed lag`；
**仅当**存在合适对照市场（同类品种、未受同等冲击）时才考虑 `Difference-in-Differences`。

## 5. 价格层级必须分开（§八十三）
分别研究并分别报告：**farmgate（产地收购价）/ purchase / wholesale（批发）/ retail（零售）**。
**禁止**把不同层级混成一条“玉米价格”。

## 6. 已知的数据约束（来自 Phase 1–3 的实测）
- 沈阳**批发/零售**日度数据较全（蔬菜 10 种 + 零售 58 种），但**玉米不在其中**；
- 省级周报含**产销地收购价**（如“铁岭市昌图县玉米 2.24 元/公斤”），属 **farm_gate**；
- 城市级价格历史多为**农资**，**不是玉米**。
→ 预注册：**优先 farm_gate 与省级**；若玉米批发/零售不可得，**标记 NOT_FEASIBLE**，不以其他作物替代。

## 7. 报告要求
区间化（median + 50%/80%/95%）；**同时报告季节性免疫效果**（即：扣除季节轨迹前后结论是否改变）。
