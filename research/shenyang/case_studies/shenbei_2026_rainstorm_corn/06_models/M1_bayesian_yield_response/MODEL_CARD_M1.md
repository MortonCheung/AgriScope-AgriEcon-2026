# MODEL_CARD_M1.md — 模型卡

| 项 | 值 |
|---|---|
| 模型名称 | **M1′ 沈北玉米小样本贝叶斯单产响应模型** |
| 版本 | v1.0（2026-09-22） |
| 研究问题 | 在控制极简长期趋势后，**抽雄—吐丝期极端降水**是否对沈北年度玉米单产提供**额外、稳定、可预测**的信息？ |
| 适用范围 | 沈北新区（单区、单 ERA5 网格点），2018–2025 训练域；**区域尺度** |
| 结果变量 | `corn_yield_kg_ha`（玉米单产，kg/ha），**log 尺度**建模 |
| 输入变量 | `time_index`（长期趋势，标准化）、`primary_rain_exposure = repro_precip_max_5d`（mm，标准化） |
| 训练年份 | 2018–2025 |
| 样本量 | **n = 8** |
| 数据来源 | 单产：沈阳统计年鉴(A)/沈北区级年鉴(B,2025)；暴露：ERA5 再分析(D)；物候：GDD 模型估计 |
| prior 来源 | **无 Class A 数值文献先验**（4 篇论文均为淹水天数→减产，属 Class C）；采用 S0 skeptical / S1 方向弱信息 / S2 折扣宽先验 |
| likelihood | `log Y_t = α + β_T·Z(T_t) + β_R·Z(R_t) + ε_t`，`ε ~ Normal(0, σ)` |
| 采样器 | 自实现自适应随机游走 Metropolis，4 链 ×(5000 warmup+5000 draws)；**无 PyMC**（环境 Python 3.9） |
| 验证方法 | Exact Leave-One-Year-Out（M0 vs M1，逐折重拟合、逐折标准化）＋ 后验预测检查 ＋ prior 敏感性 ＋ 小样本可识别性模拟 |
| 模型局限 | n=8；暴露为**再分析**；主变量是**降雨暴露而非 waterlogging**；2026 属**强外推**；无常对照区县 |
| 2026 是否外推 | **是 —— STRONG_EXTRAPOLATION（ZR≈+4.25 SD）** |
| 能回答什么 | ① 2018–2025 单产趋势（正、可识别）；② 降雨暴露系数的**后验分布**；③ 该暴露对未见年份**是否提供额外预测价值**（结论：否） |
| **不能回答什么** | ❌ 暴雨导致的**因果**减产；❌ 真实损失；❌ 无灾害/无干预世界的**定量**结果；❌ 分区县/地块级影响 |
| 反事实资格 | **NOT_ELIGIBLE**（Gate C FAIL + Gate E 强外推） |

## 关键后验（S0，主设定）
- `β_R`：median = **−0.0216**，95% CrI = **[−0.0739, 0.0379]**，P(β_R<0) = **0.775**
- `β_T`：median ≈ **0.107**（每 1 SD 时间趋势），95% CrI ≈ [0.035, 0.174]（**明显为正**）
- `α` ≈ 8.986（⇒ 基准单产 ≈ 7,970 kg/ha）；`σ` ≈ 0.083

## 使用警示
> **本模型是 response / association model，不是 causal model。**
> 任何引用必须写明：`n=8`、`再分析暴露`、`2018–2025`、`未通过 LOYO 增量检验`、`2026 强外推`。
