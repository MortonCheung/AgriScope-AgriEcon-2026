# DATA_REQUIREMENTS.md — 数据需求表

本表定义研究所需变量、目标粒度与来源优先级。状态列与 [RESEARCH_TREE.md](RESEARCH_TREE.md)、[DATA_GAP_MATRIX.md](DATA_GAP_MATRIX.md) 保持一致。

## 来源优先级
- **S 级**：国家统计局、中国气象局、辽宁省/沈阳市统计局、沈阳/辽宁统计年鉴、沈北新区政府及农业农村/水务部门、省农业农村厅、市农业农村局、省水利厅、市水务局。
- **A 级**：国家/省级科研院所、中科院、中国农科院、辽宁省农科院、同行评议论文、官方农业技术规范、国家/行业标准。
- **B 级**：新华社、辽宁日报、沈阳日报等权威媒体。
- **C 级**：其他网站/聚合/商业数据库（仅作线索）。

## 数据质量等级
`A 官方直接统计/观测 · B 官方资料可明确提取 · C 权威科研/论文 · D 遥感/再分析/模型 · E 新闻文字证据 · F 推算/估计`
