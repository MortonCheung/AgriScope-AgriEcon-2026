## 项目名称
《2026 年 7 月沈北新区极端暴雨对玉米生产影响及反事实推演研究》

本研究首先是一项**严肃的数据分析、农业气象、预测建模与反事实研究**；网页动画仅在研究结果产出后用于展示，**本阶段完全不碰前端**。

## 研究目标链条（最终要打通）
```
极端降雨 → 前期土壤/水分状态 → 农田渍涝 → 玉米生育阶段受胁迫
→ 玉米单产变化 → 总产量变化 → 农业经济影响
```
以及人为干预支链：
```
气象预警 → 排涝/疏渠/农技措施 → 缩短积水时间/降低灾害强度 → 降低玉米产量损失
```

## 反事实世界（最终目标，非本阶段）
- A 现实世界：实际天气 + 实际干预
- B 无灾害世界：正常天气 + 正常生产
- C 无干预世界：实际暴雨 + 假定不排涝
- D 提前24小时干预世界
- E 提前48小时干预世界
- F 压力测试世界：进一步增强极端降雨

> **本阶段不输出上述世界的结果**，只回答：我们有哪些数据、缺哪些数据、真实世界发生了什么、现有数据是否足以支撑后续建模。

## 空间口径（强制）
```
辽宁省 > 沈阳市 > 沈北新区 > 街道/乡镇 > 村 > 站点 > 栅格/网格点
```
禁止：沈阳市数据冒充沈北；辽宁省数据冒充沈北；单乡镇代表全区而不注明。

## 研究原则（红线）
1. **真实性第一**：严禁编造、按新闻补数字、跨层级冒充、预测当观测、无法确认年份强归2026、为填表而插值。
2. 无法确认者必须标注：`missing / unknown / not_available / estimated / model_output`。
3. 所有数据必须有来源，进入正式分析的数据必须能通过 `source_id` 找回原始来源（见 `01_sources/DATA_SOURCE_REGISTRY.csv`）。
4. LLM 不得进入数值核心模型；核心损失数字不得由 LLM 生成。
5. 每完成一步必须验证（行数/时间范围/缺失率/重复率/单位/空间范围/异常值/来源覆盖率）。

## 数据质量等级
```
A 官方直接统计/观测        B 官方资料可明确提取
C 权威科研数据或论文        D 遥感/再分析/模型
E 新闻文字证据             F 推算或估计（不得作未说明的“真实值”）
```
