## 2. 关键认知基线（承接 Phase 4，本轮不得违反）

1. **M1 已证伪并禁用**：n=8、加入极端降雨后 LOYO 预测恶化、2026 属强外推（ZR=+4.25）→ 不得用年度模型做反事实。
2. **M2 当前资格 = `ELIGIBLE_FOR_DESCRIPTION_ONLY`**（G1=0、无负样本、SAR 与易感性 ρ=0.05）→ **只能描述 2026，不能做无灾害世界**。
3. **"(暂无公式到 fitted r) → 不能推持续时间 → M3 不可启动**。
4. **坐标纪律**：EPSG:32651（UTM 51N）；禁止用 EPSG:4326 算面积/距离。
5. **空间精度上限**：受最弱数据源约束（土壤缺失、降雨单点、DEM 30 m、SAR ~10 m、证据点误差 3–5 km）→ **不输出米级灾害图**。
