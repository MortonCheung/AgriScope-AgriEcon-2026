# PHENOLOGY_MODEL.md — 玉米物候模型（P2-05）

> 输出：`03_clean/phenology/corn_phenology_reference.csv`、`05_analysis/05_phenology/corn_phenology_yearly_gdd.csv`
> 方法：**GDD（生长度日）模型**。基温 10℃、上限 30℃；播种日由官方适播窗内的温度判据确定。

## 1. 模型定义

```
GDD_day = max(0, min(Tmean, 30) − 10)          # Tmean=(Tmax+Tmin)/2
播种日  = 官方适播窗(4-20~5-10)内 5日滑动均温首次 ≥ 10.5℃ 的日期
阶段日  = 累计 GDD 首次达到阈值的日期
```

**GDD 阈值（经本地作物日历标定）**：

| 阶段 | 累计 GDD 阈值 |
|---|---|
| 出苗 emergence | 80 |
| 拔节 jointing | 350 |
| 大喇叭口 bells | 560 |
| **抽雄 tasseling** | **780** |
| **吐丝 silking** | **840** |
| 灌浆 grain_filling | 1200 |
| 成熟 maturity | 1700 |

> 标注：阈值为**“标定后模型估计”**，标定目标是复现本地作物日历（抽雄≈7月中旬、成熟≈9月下旬-10月上旬）。**不是田块实测物候。**

## 2. 2026 年物候（GDD 推算）

| 阶段 | 日期 |
|---|---|
| 播种 | 2026-04-20 |
| 出苗 | 2026-05-09 |
| 拔节 | 2026-06-03 |
| 大喇叭口 | 2026-06-24 |
| **抽雄** | **2026-07-10** |
| **吐丝** | **2026-07-14** |
| 灌浆 | 2026-08-05 |

→ **2026-07-13 暴雨落在“抽雄期（抽雄日 7-10 → 吐丝日 7-14）”内**。

## 3. 与官方/日历的一致性检验

| 检验 | 模型结果（2026） | 官方/日历 | 一致 |
|---|---|---|---|
| 播种期 | 04-20 | 4 月下旬–5 月上旬（`SRC-SY-NYJ-2026-JSZ`） | ✅ |
| 抽雄期 | 07-10 | 作物日历“7 月抽雄”；官方“7 月玉米生长关键期” | ✅ |
| 吐丝期 | 07-14 | 作物日历“7–8 月” | ✅ |
| 成熟期 | 08-29（GDD 达 1700） | 作物日历“9 月下旬–10 月上旬” | ⚠️ **偏早约 1 个月**（见局限） |

多年中位抽雄日 7 月 6–15 日（1991–2026），与“7 月生长关键期”一致。

## 4. 阶段概率（不确定性，替代“指定单一日”）

对 1991–2020 共 30 个完整年份，统计 **7 月 13 日**落入各阶段的频率（经验分布）：

| 阶段 | 概率 |
|---|---|
| **抽雄期 tasseling** | **0.50** |
| 大喇叭口期 bells | 0.33 |
| 吐丝期 silking | 0.17 |
| （抽雄+吐丝合并） | **0.67** |

**综合判断**：2026 自身 GDD 指向 **抽雄期（近吐丝）**；气候经验分布给出“抽雄 0.50 / 大喇叭口 0.33 / 吐丝 0.17”的不确定区间。
→ **结论：2026-07-13 玉米处于抽雄—吐丝期，置信度“中”，最可能为抽雄期。**

## 5. 局限（必须随结论引用）
1. **无田块实测物候**（`not_available`），GDD 阈值由日历**标定**，非本地观测拟合。
2. 用**ERA5 网格点气温**算 GDD（Level C，再分析），非田块温度。
3. 播种判定用**气温**近似**土壤温度**（官方判据是 5–10cm 地温稳定 8–10℃），存在系统差。
4. 成熟期推算偏早，说明 GDD 基温/上限或品种熟期参数仍需本地资料校准。
5. 未考虑品种熟期差异、覆膜、播期年际调整等人为因素。
