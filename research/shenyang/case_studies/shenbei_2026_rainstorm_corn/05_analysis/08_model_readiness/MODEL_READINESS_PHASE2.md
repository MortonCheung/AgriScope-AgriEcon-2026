# MODEL_READINESS_PHASE2.md — Phase 2 模型就绪度等级（§31）

## 等级定义

| 等级 | 含义 |
|---|---|
| LEVEL 0 | 没有足够数据 |
| LEVEL 1 | 只能描述 |
| LEVEL 2 | 可做相关/机制研究 |
| LEVEL 3 | 可做预测 |
| LEVEL 4 | 可做因果估计 |
| LEVEL 5 | 可做反事实模拟 |

## 逐模型判定

| 模型 | 目标 | 判定 | 理由 |
|---|---|---|---|
| **M1 正常玉米单产预测** | 天气→单产 | **LEVEL 1** | n=8、p=12、df<0；仅能做描述/趋势（LOYO 仅趋势项可用）。**未达 LEVEL 3（预测）** |
| **M2 极端降雨风险模型** | 降雨→渍涝风险 | **LEVEL 2** | 降雨端充足（1991–2026），可做极端指数与风险分级；但缺地形/排水/积水观测，**不能预测所谓“哪里会涝”** |
| **M3 渍涝损伤模型** | 渍涝→减产 | **LEVEL 1** | 有机制与文献先验，但**无沈北渍涝观测、无 2026 灾损**，无法标定 |
| **M4 干预效果模型** | 干预→减损 | **LEVEL 1** | 有个案干预时间线，但**无对照、无损失因变量**，反事实不可识别 |
| **M5 最终反事实模型** | do(Weather/Intervention) | **LEVEL 1** | 依赖 M1–M4；当前不可执行 |

## 总体就绪度

```
M1 LEVEL 1 · M2 LEVEL 2 · M3 LEVEL 1 · M4 LEVEL 1 · M5 LEVEL 1
```

- **最高等级仅 LEVEL 2**（极端降雨风险描述），**无任何模型达到 LEVEL 3（预测）**。
- 与 Phase 1 结论一致（A/C/D = NOT_READY，B = PARTIALLY_READY），本轮量化后更精确：
  **M2 由“部分就绪”明确为 LEVEL 2（可做相关/机制，不可预测）**。

## 提升等级的关键动作
| 目标 | 需要什么 |
|---|---|
| M1 → LEVEL 3 | 历史序列扩到 ≥15–20 年（或引入对照区县面板 / 作物模型） |
| M2 → LEVEL 3 | DEM + 水系/沟渠 + 排水设施 + 积水观测 |
| M3 → LEVEL 2/3 | 2026 渍涝范围（遥感/台账）+ 分区县灾损 |
| M4 → LEVEL 3+ | 全区排涝台账 + 未干预对照 + 积水时长 |
| M5 → LEVEL 3+ | 上述全部 + 结构参数可识别 |
