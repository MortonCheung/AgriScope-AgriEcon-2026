# MODEL_READINESS_REPORT.md — 模型就绪度审计

> 判据：**是否具备该模型所需的识别条件**（样本量、关键变量、口径一致性、对照组），
> 结论只能取 `READY / PARTIALLY_READY / NOT_READY`，**不为了推进项目一律判 READY**。

---

## 1. 样本与数据结构现状（先看规模再谈模型）

| 维度 | 现状 | 是否支持复杂模型 |
|---|---|---|
| 沈北玉米**年度样本 n** | **8**（2018–2025） | ❌ 远不足 |
| 特征维度（天气变量） | 日值 9+ / 小时 4 | ⚠️ 特征数 ≥ 样本数 |
| 缺失率 | 玉米序列 0%（8年全有）；气象 0% | ✅ |
| 时间覆盖 | 玉米 8 年；气象 1991–2026 | ⚠️ 玉米短 |
| 空间覆盖 | **单区单点**（1 个区、1 个网格点） | ❌ 无空间变异 |
| 干预观测 | 个案 1 例 | ❌ |

> 结论：**n=8 且单区单点**，不满足任何数据驱动复杂模型（RF/XGBoost）的识别要求；
> 若强行训练，将获得**不可靠的“因果”结论**。

## 2. 模型 A：天气 → 年度玉米单产

| 前提 | 状态 |
|---|---|
| 足够年度样本 | ❌ n=8 |
| 关键生育阶段天气特征 | 🟡 有日/小时气象，但无田块物候 |
| 连续玉米单产 | ✅ 2018–2025 |
| 数据口径一致 | 🟡 2025 为区级年鉴（亩/万吨）|

**判定：`NOT_READY`**
理由：样本量 8 与特征维度相当，无法区分“天气效应”与“技术趋势/年际噪声”；生育期物候为区域粒度。
**可做的替代**：仅做**描述性/趋势分解**（已做）与**单年事件叙事**，不做回归“找因果”。

## 3. 模型 B：极端降雨 → 渍涝

| 前提 | 状态 |
|---|---|
| 高频降雨 | ✅ 逐小时 2015–2026（再分析） |
| 前期湿度 | 🟡 ERA5-Land（待并入） |
| 积水观察 | 🟡 仅定性/个案，无网格积水 |
| 地形 | ❌ 无 DEM |
| 排水能力 | ❌ 无设施矢量 |

**判定：`PARTIALLY_READY`**
理由：**降雨端充足**，但**水文/地形/排水端缺失**，无法建立“同雨不同涝”的空间判别。
**下一步**：采集 DEM + 沟渠 + 泵站 + 土地利用，方可将“降雨→渍涝”升级为可建模型。

## 4. 模型 C：干预 → 损失降低

| 前提 | 状态 |
|---|---|
| 干预时间 | ✅ 个案时间戳完整 |
| 干预强度 | 🟡 个案（12台8寸泵）；全区缺 |
| 干预前后灾情 | ❌ 无区级灾损 |
| 对照地区/历史对照 | ❌ 无 |

**判定：`NOT_READY`**
理由：无对照组、无灾损因变量。**当前只能做时间线与个案叙述。**

## 5. 模型 D：最终反事实模型（B/C/D/E/F 世界）

| 依赖 | 状态 |
|---|---|
| 单产响应函数（模型A） | ❌ NOT_READY |
| 渍涝判别（模型B） | 🟡 PARTIALLY |
| 干预效果（模型C） | ❌ NOT_READY |
| 灾损/产量基准（2026） | ❌ 未发布 |

**判定：`NOT_READY`**

## 6. 建模方法适用性研究（当前只研究，不执行）

| 方法类别 | 方法 | 是否适用 | 原因 |
|---|---|---|---|
| 描述与异常识别 | 历史百分位、Z-score、趋势分解、极端指数 | ✅ **适用** | 单序列即可，本阶段已用 |
| 非线性响应 | GAM / 分段回归 / spline / threshold | ❌ | 需足够样本；n=8 会过拟合 |
| 预测 | 线性/岭回归 baseline | 🟡 仅作演示 | 样本过少，仅可最简线性趋势 |
| 预测 | Random Forest / XGBoost / LightGBM | ❌ | 特征≥样本，必然过拟合 |
| 时间与滞后 | distributed lag / rolling exposure | 🟡 | 高频气象具备，但缺因变量分辨率 |
| 因果与反事实 | matching / synthetic control / BSTS / DID / causal forest / SCM | ❌ | **无处理组-对照组、无干预台账、无灾损**，识别假设不满足 |

> 结论：**当前唯一稳健可做的是“描述 + 异常识别 + 趋势分解”**；其余方法待数据条件改善后逐条评估。

## 7. 就绪度汇总

| 模型 | 判定 | 一句话理由 |
|---|---|---|
| A：天气→年度单产 | **NOT_READY** | n=8、单区单点，识别不足 |
| B：极端降雨→渍涝 | **PARTIALLY_READY** | 降雨端够，地形/排水端缺 |
| C：干预→损失降低 | **NOT_READY** | 无对照、无灾损 |
| D：最终反事实 | **NOT_READY** | 依赖 A/B/C 与 2026 灾损 |

**总体：`NOT_READY`（四个模型中 0 个 READY，1 个 PARTIALLY_READY）。**
