# MODEL_READINESS_PHASE4.md — Phase 4 模型就绪度（M2 专用等级）

## M2 专用等级（§71）
```
M2-L0 无空间数据
M2-L1 地形易感性描述
M2-L2 多源事件重建
M2-L3 空间预测模型
M2-L4 经过独立空间验证
M2-L5 可用于反事实情景
```

## 判定
| 等级 | 是否达到 | 依据 |
|---|---|---|
| M2-L0 | ✅ | 有 DEM/耕地/水系/降雨/SAR |
| **M2-L1（地形易感性描述）** | ✅ | 完成 7 个地形指标 + 3 个排水相关距离；物理合理性 9/10 方向一致 |
| **M2-L2（多源事件重建）** | ✅ | 三层融合（易感性 + 事件暴露 + 观测证据）→ M2R_risk；含风险与置信度分层 |
| M2-L3（空间预测模型） | ❌ | **无监督标签**（G1=0、可靠负样本=0）→ 依 §36/§34 不训练监督模型 |
| M2-L4（独立空间验证） | ❌ | 无 G1 标签与独立地块级验证集 |
| M2-L5（可用于反事实） | ❌ | 资格判定 = `ELIGIBLE_FOR_DESCRIPTION_ONLY` |

## 结论
> **M2 = M2-L2（多源事件重建）**。
> 可以：描述 2026 渍涝易感区、解释“为何更易涝”、给出风险×置信度双图。
> 不可以：预测未来降雨情景、进入无灾害世界定量反事实。

## 与 Gate 判定一致
Gate A PASS / B PASS / C CAUTION / D CAUTION / E CAUTION / F PASS → **ELIGIBLE_FOR_DESCRIPTION_ONLY**。
（Gate C/D/E 均为 CAUTION，源于：证据点空间误差 3–5 km、SAR 与易感性一致性低（ρ=0.05）、无 G1 标签。）

## 升级到 L3/L4 所需
1. 田块级（G1）受淹标签或经核验的负样本；
2. 完整排水沟渠/泵站矢量；
3. 多时相 SAR（含多年同期对照）或光学可用观测；
4. 高精度裸地 DEM（现为 DSM）。
