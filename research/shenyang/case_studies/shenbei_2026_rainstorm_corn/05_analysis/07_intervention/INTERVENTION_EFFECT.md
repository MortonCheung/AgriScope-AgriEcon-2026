## 2. 个案效果链（唯一有较完整时间戳的案例：新城子街道八间房村）

```
7-13/14  极端暴雨，排水站南侧水田区积水最深>1m，8000余亩受淹（水稻临抽穗、玉米关键期）
7-14     村支书对接区农业农村局，紧急协调排水设备（初期效果未达预期）
7-15     增援：两台大功率泵车+一台50泵+三组8寸管 + 一台应急排水车 → 共12台8寸泵
         排水路径：左小河 → 辽河
7-18 下午 田间积水基本排净
7-25     持续跟踪安全与生产恢复
```

**可推断（高可信）**：本例中**干预显著缩短了积水时间**（7-14 启动 → 7-18 排净，约 4 天完成 8000 余亩排涝），
官方/媒体表述为“作物得以起死回生、最大限度减少损失”。

## 3. 预警—行动时间差（可计算）

- 预警锚点：**7-13 09:10**（红色预警 / 最高一级响应）。
- 个案行动锚点：**7-14**（八间房村协调设备）、**7-15**（设备增援/兴隆台新民村清沟排水）。
- → **预警提前量约 15–39 小时**（相对 7-14 至 7-15 的行动）。
- 该差值**尚未**与损失挂钩（缺损失数据），仅作为“可缩短积水时间”的干预窗口证据。

## 4. 为什么当前**不能**量化干预效果

| 量化前提 | 现状 |
|---|---|
| 处理组/对照组（受干预 vs 未干预、可比的地区或历史年份） | 🔴 无 |
| 干预强度连续变量（泵数量、排涝面积、积水时长） | 🟡 仅个案 |
| 干预前后灾情可比指标 | 🔴 无区级灾损 |
| 反事实基准（无干预会怎样） | 🔴 无模型/无对照 |

## 5. 结论
- **可以做**：干预时间线重建、个案效果叙述、预警—行动时差计算、干预类型学。
- **不能做**：干预的**定量减损率**（需要对照与灾损数据）。
- **下一步**：优先采集①全区排涝台账（泵/面积/时长）②同期未排涝或排涝较晚地块的灾情对照 ③历史同类暴雨年份作为合成对照。
