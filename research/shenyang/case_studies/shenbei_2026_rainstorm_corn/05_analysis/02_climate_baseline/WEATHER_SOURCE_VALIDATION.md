# WEATHER_SOURCE_VALIDATION.md — 多源气象交叉验证（P2-04）

> 目的：判断**再分析（ERA5）能否用于补长期历史**。
> 数据：ERA5（Open-Meteo，沈北网格点 42.003513,123.53712）vs NASA POWER（MERRA2，点 123.521,42.052,128.37）。
> 重叠期：**2083 天**（2021-01-01 ~ 2026-09-14）。
> 输出：`weather_source_validation.csv`、`03_clean/weather/pnb_daily_1991_2026.parquet`。

## 1. 数据层级标注（强制）

| 层级 | 定义 | 本案例对应 |
|---|---|---|
| Level A | 地面气象站观测 | **未取得**（中国气象数据网需实名，未绕过） |
| Level B | 官方格点数据 | 未取得 |
| **Level C** | **再分析（ERA5）** | ✅ 本研究主用（1991–2026 日值 / 2015–2026 逐小时） |
| Level D | 其他第三方再分析/聚合 | NASA POWER（MERRA2）、Open-Meteo |

> **ERA5/NASA POWER 均不得写成“沈北实测”。**

## 2. 交叉验证结果（ERA5 vs NASA POWER，2083 天）

| 指标 | 数值 | 判读 |
|---|---|---|
| 日降水相关系数 | **0.744** | 中等偏强 |
| **月累计降水相关系数** | **0.938** | 强 |
| 月累计降水偏差（ERA5−NASA） | **−6.8 mm/月** | ERA5 略偏小 |
| 极端日（≥25mm）Jaccard 一致率 | **0.391** | **弱** |
| 极端日数（ERA5 / NASA） | 52 / 44 | 数量接近，但**不是同一天** |
| 日均温 MAE | **1.45 ℃** | 可接受 |
| 日最高温 MAE | 1.21 ℃ | 可接受 |
| 日最低温 MAE | 2.16 ℃ | 偏大（夜间/地形差异） |

## 3. 结论（直接回答“能否补长期历史”）

- ✅ **可以**用于：长期**降水总量/月尺度**、**气温均值**、生长季累计、趋势与年际对比。
- ❌ **不可靠**用于：**逐日极端降水事件的识别**（Jaccard 仅 0.391）——两套再分析对“哪一天下了暴雨”分歧明显。
- ⚠️ 因此：**用再分析做“季节累计暴露”特征可信；做“某一天是否暴雨”的判据须谨慎**，并优先用**相对阈值（P90/P95/P99）**而非绝对日值。

## 4. 对 P2-06 特征工程的含义

- 生育期**累计降水、平均温度、GDD** 类特征 → 可信（月尺度相关 0.94）。
- 生育期**最大 1 日/5 日降水、暴雨日数** → 保留但标注不确定性，且阈值同时给**绝对（国标暴雨≥50mm）与相对（沈北历史 P90/P95/P99）**。
- **站点实测**仍是 P0 缺口：一旦取得，须重做极端日识别。

## 5. 局限
1. 仅一个网格点代表全区；沈北内部（东部低山 vs 西部平原）差异未刻画。
2. NASA POWER 点位（123.521,42.052）与 ERA5 点（123.5371,42.0035）**并非同点**，含约 5km 空间差。
3. 未含 Level A 实测，无法做“实测 vs 再分析”的真值校验（这是最大局限）。
