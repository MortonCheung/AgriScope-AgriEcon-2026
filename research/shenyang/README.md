## 5 分钟了解本项研究

### 1. 研究什么

沈阳市**主要蔬菜批发市场**（10 种蔬菜的价格与成交量）与**农业生产**（8 个农业区县的播种面积、产量、单产）在**气象条件**下的表现，以及极端天气事件的市场响应。

### 2. 为什么研究

沈阳是东北地区重要的农业生产与农产品集散地。已有研究多在国际大宗商品或月度以上频度报告天气—价格关系，而城市级、日度、鲜活蔬菜层面是否成立尚不清楚；同时沈阳的区县农业生产数据此前未被系统整理。本研究据此建立可追溯的两端证据。

### 3. 用什么数据

| 数据 | 范围 | 来源等级 |
|---|---|---|
| 批发价格与成交量（10 种蔬菜，日度） | 2021-01-01 ~ 2026-09-14 | A（价格）/ 单位未知（成交量） |
| 气象（ERA5 再分析网格，日度） | 2021-01-01 ~ 2026-09-14（区县 2015-2025） | A（**再分析，非气象站实测**） |
| 极端天气事件 | 算法事件（阈值识别）与官方通报**分开** | B / A |
| 区县农业生产（面积/产量/单产） | 2018-2024，8 个农业区县 | A（《沈阳统计年鉴》） |

### 4. 有哪 8 项研究

| 编号 | 标题 |
|---|---|
| A01 | 沈阳市主要蔬菜批发市场的时间结构与季节性特征 |
| A02 | 气象条件与沈阳市主要蔬菜批发市场日度响应 |
| A03 | 气象影响的滞后累积与非线性特征 |
| A04 | 极端天气事件下沈阳市蔬菜批发市场响应及 2026 年强降雨案例 |
| A05 | 沈阳市不同蔬菜的气象响应差异与市场恢复特征 |
| A06 | 沈阳市蔬菜市场量价关系风险传导与天气信息预测增量 |
| A07 | 沈阳市农业生产的区县格局与作物结构（2018-2024） |
| A08 | 气象条件与沈阳市农业单产变化的区县面板研究 |

另有综合篇 **A09**：沈阳市农业气象风险、生产响应与农产品市场表现综合研究。

### 5. 每项主要发现

- **A01**：价格季节波动明显强于成交量（季节指数极差中位 0.775 vs 0.084）。20 项趋势检验中 8 项 FDR 显著；价格仅土豆下降 3.07%/年，成交量 7 项方向不一。
- **A02**：含自回归的日度模型中，100 项核心检验仅 6 项 FDR 显著，效应量 ≤0.06 个标准差。
- **A03**：滞后窗 11/160、累积降水 10/80 显著；非线性在**控制自相关后** 7/80 显著，而不控制时会虚假地达到 69/80。
- **A04**：10 个清洁事件簇的安慰剂 p 在 0.59–0.77，与随机日期不可分辨。2026 年 7 月降雨 173.9 mm 为样本第 1/2,083，但市场响应落在普通波动范围内。
- **A05**：4 项品种×气象交互检验 3 项 FDR 显著（**探索性**）；恢复观察右删失率 51%/46%，不给出韧性排序。
- **A06**：控制价格自身滞后后成交量对价格效应中位 +0.0007（FDR 0/10）；传导两步规则未同时满足；加入天气后 RMSE 相对变化中位 −0.66%（无预测增量）。
- **A07**：8 个区县粮食面积中位相差约 8.5 倍；9 个核心作物类别均有 7 年 × 8 区县完整数据。
- **A08**：54 项面板检验 4 项 FDR 显著（强降水日数与单产正相关），但 wild cluster bootstrap p=0.057，判为**部分支持但不确定**。

### 6. 哪些结果成立

| 结论 | 状态 |
|---|---|
| 价格季节波动强于成交量 | 描述性（就数据而言成立） |
| 多数品种成交量存在长期趋势且方向不一 | 描述性 |
| 价格异常具有强持续性（AR(1) 中位 0.930） | 描述性 |
| 品种间对 7 日降水的响应斜率存在差异 | 部分支持（探索性） |
| 强降水日数与对数单产正相关 | 部分支持但不确定（wild bootstrap p=0.057） |
| 2026 年 7 月降雨为观测期最强 | 描述性 |

### 7. 哪些不成立

| 结论 | 状态 |
|---|---|
| 气象条件显著驱动日度市场价格 | 未得到支持 |
| 存在气象风险阈值 | 未得到支持 |
| 存在"天气→成交量→价格"供应传导链 | 未得到支持 |
| 天气带来市场预测增量 | 未得到支持 |
| 极端天气事件引起可检出平均市场响应 | 未得到支持 |
| 沈阳本地产量变化影响批发市场价格 | **数据不足，无法检验** |
| 极端天气造成具体量级经济损失 | **数据不足，不作陈述** |

### 8. 哪些做不了（数据约束）

1. **无货源地数据**：不知道批发市场蔬菜来自哪里 → 生产端与市场端**不能连接**。
2. **成交量单位未知**（官方未公开）→ 不能给绝对量，**禁止写「吨」**。
3. **ERA5 是再分析网格**，对极端高温有平滑：2020–2024 年 ≥35℃ 高温日为 0 → 无法研究高温胁迫。
4. **区县面板聚类数仅 8**、每作物 56 观测 → 推断精度有限。
5. **2015-2017 市级年鉴无附件**，仅康平县可用；2025 年未完整验证。
