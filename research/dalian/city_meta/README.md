# 大连城市数据包

本目录只整理数据，不包含研究结论。

## 数据分层

- `raw/`：城市相关原始数据副本/克隆
- `interim/`：从统一事实表中按城市过滤的数据
- `processed/`：已有城市级 marts / parquet 产物
