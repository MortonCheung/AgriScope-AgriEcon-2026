# 辽宁省农业农村厅 · 农产品历史价格数据采集

自动抓取辽宁省农业农村厅「农产品信息」栏目全部公开历史价格简讯，解析为 Long Format 结构化数据，并保留原文与来源以便逐条核验。

**本阶段只做数据采集与清洗**，不做网页、不做预测模型、不做可视化。

---

## 一、快速开始

```bash
pip install -r requirements.txt

python run.py crawl      # 发现并下载新增文章（增量；自动解析）
python run.py parse      # 从已保存 HTML 重新解析（不联网）
python run.py validate   # 数据质量检查
python run.py report     # 统计报告 + 作物覆盖度报告
python run.py all        # crawl → parse → validate → export → report
```

首次完整采集约需 25 分钟（1131 篇文章，限速 0.5~1.5s/请求）。

| 分类 | 路径 slug | 优先级 | 文章数 |
|---|---|---|---|

| 蔬菜 | `lnsnzyscpzjg` | P0 | 282 |
| 水果 | `lnsnzysgcpjg` | P0 | 283 |
| 农资 | `lnsnzynzcpscjg` | P1 | 283 |

畜禽水产（`lnsnzycscpjg`）暂不采集，配置已预留于 `config/sources.yaml` 的 `categories_future`，启用即可。

### 站点实测结论（非推测）

1. **分页是 JS 驱动的**。分页链接没有 `href`，真实目标 URL 藏在 `<a title="下一页" tagname="/…/{module_uid}-{n}.shtml">` 中。
   已实测该 URL 可直接 HTTP GET 返回 200，**因此不需要 Selenium / Playwright**。
2. **文章 ID 有两种形态**：近期是数字时间戳（`2026091711242671508`），早期是大写十六进制串（`D2133A94E5ED40AFA01935FA235B9730`）。
   所以绝不按 URL 日期或数字 ID 推算文章，一律从列表页 DOM 实际读取。
3. **页码越界会串模块**（如农资第 16 页返回另一个数据集并报「共38页」），故严格按「下一页」跟随 + 总页数上限，不做 URL 推算。
4. **正文容器**为 `div.TRS_Editor`（TRS CMS 标准），备选 `div.nr` / `div.pages_content`，失败时记日志。
5. `robots.txt` 返回 404，站点未声明抓取限制；本项目仍采用低频限速（并发 2、间隔 0.5~1.5s）。

## 三、历史格式演变（解析器必须兼容的变体）

调研了 2021—2026 全部年份的正文，存在以下差异，解析器均已覆盖：

**标题三代写法**
```
2021—2023  辽宁省内第10周主要粮油品种市场价格简讯      （无年份）
2024       2024年辽宁省内第26周主要农资产品市场价格简讯  （年份在前）
2025—2026  2026年第37周辽宁省主要粮油产品价格简讯      （现行）
```

**统计周期**：绝大多数为「本周（…）」，但 2021 年蔬菜类写作「**上周**（…）」；
2025 年第 2 周蔬菜一篇还缺左括号（「本周2025年1月6日至…）」）。

**价格句式（十余种）**
```
【大米】平均价格为4.48元/公斤                    （2021—2024）
【大米】批发均价为4.52元/公斤                    （2025—2026）
辽宁大豆收购均价为每公斤4.50元                    （单位倒装）
最高收购价格出现在辽阳文圣区，为3.02元/公斤        （地点在前）
最高价格为3.10元/公斤，出现在辽阳灯塔              （地点在后）
最高价格为鞍山铁西区每公斤5.00元                  （地点 + 倒装）
最高价出现在阜新市蔬菜批发市场，为10.00元/公斤      （2021 水果）
其中，沈阳市1750.00元/吨，鞍山市1750.00元/吨      （农资城市列举）
沈阳价格为2080元/吨，抚顺2030元/吨                （独立城市行，无【】标签）
城市价行单独成段，产品名需从上一行【产品】继承
```

**涨跌表达**：上涨/下降/持平之外，还有**回落**、下跌、下滑、微降、上升、增加，
以及「小幅/微幅/明显/有所」等修饰；历史写法「环比持平（-0.35%）」括号内给实际值。

**其它**：产品名存在字间空格（「【豆 油】」）；数字存在排版空格（「2960 .00元/吨」）。

## 四、解析方案

**不是**「一个巨大正则扫全文」，而是分层确定性规则：

```
HTML → 定位正文容器(TRS_Editor) → 段落切分 → 识别章节(一/二/三)
     → 【产品】锚点 → 扫描所有价格锚点 → 依据锚点前后文判定
       记录类型 / 地点层级 / 涨跌 / 价格类型 → Long Format
```

价格锚点同时支持正向「4.50元/公斤」与倒装「每公斤4.50元」；
地点解析区分「X为{price}」（地点在动词前）与「是X{price}」（地点在动词后）两种句式；
「出现在X」需判断属于本句还是上一句。全程**不调用 LLM**（手册第二十一节要求）。

## 七、已知数据缺陷（未擅自修正）

1. **6 篇官方链接 404**（蔬菜 2026 第 3、22、26、28 周；农资/粮油 2026 第 12 周）。
   列表页仍能看到条目，但正文页已失效。
2. **5 篇正文统计周期年份笔误**（网站录入错误，解析器忠实保留原文）：
   - 农资 2024 第 1 周「2024年1月1日至**2023**年1月5日」
   - 农资 2024 第 2 周「2024年1月8日至**2023**年1月12日」
   - 农资 2024 第 22 周「2024年5月27日至2024年**6月30日**」
   - 蔬菜 2022 第 2、3 周「**2021**年1月6日至2022年1月12日」等
3. **周次缺口 13 组**（状态 `missing_week_candidate`，需人工复核，**不判定为抓取遗漏**）：
   2024 年第 7、39 周与 2025 年第 4、14、38 周四类同时缺失，大概率为官方节假日未发布。
4. **市级数据分布极不均衡**：只有农资类逐市报价；粮油/蔬菜/水果只给「全省均价 + 全省最高价地区 + 全省最低价地区」，
   因此某市记录数取决于它多常被列为极值地区。六城市中**沈阳的水果仅 2 条、蔬菜 5 条；
   铁岭、锦州、丹东的水果与蔬菜为 0**。若要按城市建模，粮油/蔬菜/水果需改用省级序列，
   或后续接入商务部市场级日价格数据补齐市级维度。
5. **127 条 `geo_level = market`**：历史文章极值地点写作市场名（「黄海超市」），
   无城市归属，`location_raw` 保留原文，`city`/`county` 为空。

## 八、字段约定要点

- `price` + `original_unit` 是原文照录，**永不换算、不删除**；`standard_price`/`standard_unit` 是额外换算列（统一到元/公斤）。
- `location_raw` 永远保留原文（如「鞍山台安县农贸市场」）；`city`/`county` 只是新增的标准化字段。
- 沈北新区 → 沈阳市 → 辽宁省，绝不会被提升为独立城市。
- `mom_change_pct` / `yoy_change_pct` 采用**百分点**（2.79 表示 +2.79%），非小数。
- `source_text` 保存该数字来自的原句，可逐条回溯核对。

完整字段说明见 `data/processed/data_dictionary.md`。
