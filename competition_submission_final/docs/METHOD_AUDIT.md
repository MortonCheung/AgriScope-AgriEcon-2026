## P0-A　季节策略的未来标签泄漏

### 判定：成立

**代码位置**：`final/backtest.py::_seasonal_hist()` / `_seasonal_pick()`

修复前逻辑：

```python
hh = hist[(hist["month"] == t.month) & (hist["date"] < t)]
hh = hh[hh["rel_ret"].notna()]
```

`rel_ret = target_mean_price_next_30d / price - 1`，其中目标的窗口是 (d, d+30]。
因此历史样本 d 的标签**可获知日期是 d+30（+发布滞后）**，而不是 d。
用 `d < t` 过滤，会纳入 `t-29 <= d < t` 的样本——这些样本的标签窗口延伸到 t 之后，
**在决策日 t 根本不可观察**。

举例：t = 2025-03-10 时，样本 d = 2025-03-05 的标签窗口为 (03-05, 04-04]，
其中 03-11 至 04-04 的价格在 03-10 尚未发生。

### 证据

| 用例 | 修复前 | 修复后 |
|---|---|---|
| **P0-A1** 历史样本标签窗口未闭合时不得参与评分 | ❌ 选到「西红柿」＝使用了未成熟标签 | ✅ 正确排除，选中窗口已闭合的「黄瓜」 |
| **P0-A2** 扰动决策日之后的标签，选择不得改变 | ❌ 选择随扰动改变（西红柿 → 黄瓜） | ✅ 选择保持不变 |

P0-A2 的构造方式：仅有一个样本 d\* 的窗口在 t 处未闭合，且 d\* 是该月 argmax 的唯一决定者；
把 d\* 的相对收益从 +0.90 改为 −0.90（模拟"决策日之后的价格变化"），
修复前的选择随之翻转，修复后保持不变。

### 修复

```python
ds["label_avail_date"] = ds["date"] + pd.Timedelta(days=int(h) + int(extra_lag_days))
...
hh = hist[(hist["month"] == t.month) &
          (hist["label_avail_date"] <= t) &
          (hist["rel_ret"].notna())]
```

`LABEL_AVAIL_EXTRA_LAG_DAYS = 1`，用于保守覆盖数据发布/整理滞后（原始平台按日发布，
保守多计 1 天）。该参数可配置，便于敏感性分析。

### 影响

季节策略（`Seasonal`）的历史样本池被收窄：每个决策切点最多只能用
**决策日前 31 天以前**的同月样本。step7 口径下，每个切点的可用同月样本减少约 4 个日期。
Seasonal 的成绩在修复后发生变化，**按新结果为准**（见 `FINAL_RESULTS.md`）。

## P0-B　随机基准：混合了"期望"与"实现"，且高 HRI 命中率被布尔化

### 判定：成立

**代码位置**：`final/backtest.py::_expectation_rec()`

修复前：

```python
thr = hr.quantile(0.90)
...
"high_hri": float((hr >= thr).mean()) >= 0.10,
```

`thr` 取池内 90 分位，因此 `(hr >= thr).mean()` 恒约为 0.10，`>= 0.10` 判定为 `True`。
汇总时对该布尔列取均值 → **随机策略的高 HRI 命中率恒为 100%**。
这是一个纯粹的度量错误，与市场无关。

同时存在第二层混淆：`_expectation_rec` 用**池内均值**（数学期望）填入 `realized_return`，
却也用池内均值/中位数等填入 `realized_worst`、`win` 等"实现"字段。
**期望结果的均值是合法的，但"最差单次""P05""下跌概率"不能由池的横截面统计冒充某一次随机实现的风险分布。**

### 证据

| 用例 | 修复前 | 修复后 |
|---|---|---|
| **P0-B** 随机策略平均高 HRI 命中率 | ❌ FAIL：字段类型为 `bool`，汇总恒为 100% | ✅ PASS：平均命中率 **0.100**（池内占比口径，符合 90 分位阈值预期） |

### 修复

1. `high_hri` 改为记录**池内高 HRI 作物占比本身**（连续值，即随机选择的命中概率），不再布尔化；
2. 新增 `stat_type` 字段，显式区分 `expected`（解析期望）与 `realized`（单次实现）；
3. 随机策略的**风险分布**改由多种子蒙特卡洛抽样评估（500 次不同种子），
   分别报告"期望结果"与"随机实现分布"，两者不得混用。
