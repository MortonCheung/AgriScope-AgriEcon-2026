## 二、农业经济实证论文的写作规范（据参考论文提炼）

### 2.1 引言

**规范**：采用五步链条——现实关切 → 福利含义 → 成因分类 → 由已有发现推出疑问 → 研究意义。禁止从"本文使用某某模型"开始。

**本文的应用**：现有引言第一段已从产业背景切入，但缺少"福利含义"一步。新稿将明确写出：价格剧烈波动对生产者的含义是**收益不确定与资源配置错位**，对消费者是支出波动；并说明为什么这种波动不会被市场自我纠正（信息不完全 + 供给反应滞后）。

### 2.2 文献综述

**规范**：按问题组织；每篇文献写明"谁、研究了什么、发现了什么"；不足要具体，不用"研究较少""有待深入"；不得声称"现有研究普遍忽略某问题"。

**本文的应用**：原稿按"四类文献"罗列。新稿改为三个问题组织：①蔬菜价格波动如何形成与传导；②农户如何依据价格形成预期并调整生产；③市场信息与预测在风险管理中的位置。并在每个问题末尾给出本文的处理方式。

### 2.3 方法叙述

**规范**：遵循"研究问题决定指标 → 指标决定数据处理 → 数据条件与评价目标决定模型选择"的顺序；为方法选择给出理由（既有做法的具体局限 + 所选方法如何对应解决）；方法设定后逐符号解释经济含义；算法名称、软件版本、数据指纹等工程信息尽量下沉到附录。

**本文的应用**：新稿在第四章开头新增一节"方法选择的两个问题"，说明为什么必须设朴素基线（回答"是否需要用模型"）、为什么必须做配对比较（参考 [13] 发现蔬菜价格存在共同因子驱动，若分别比较均值会把共同市场冲击计入策略能力）。

### 2.4 数据

**规范**：来源 → 口径 → 覆盖与规模 → 描述特征 → 适用范围与已知缺陷；适用范围在数据章交代，不推迟到结论。

### 2.5 结果

**规范**：表格只呈现证据；正文回答四问——证明了什么？不支持什么？是否与预期一致？还有没有其他解释？禁止复述表中数字。

**本文的应用**：第七、八章全部改写，每个表后按上述四问组织；对"为何密集切点显著、不重叠切点不显著"给出三种并列解释并标注证据等级。

### 2.6 机制与解释

**规范**：机制来自理论，发现来自数据，两者分工明确；机制拆成可辨识的环节，并说明本文能检验哪一环、不能检验哪一环。

**本文的应用**：追高机制拆为三环——价格上行形成扩种诱因（本文不可观测，仅引 [15] 说明农户对涨价反应更强）→ 供给调整存在时滞（理论来源 [17][18]）→ 后续价格承压（本文可检验，第五、七章）。明确写出第一环不属本文证据。

### 2.7 不利结果与局限

**规范**：不利结果作为正式结论的一部分呈现，不藏在稳健性小节；局限与结论一一对应。

**本文的应用**：第十章把"预测改进依赖模型选择方式""不重叠口径下无策略显著""四组配对全部不显著"与正向发现**并列陈述**。

### 2.8 结论与政策建议

**规范**：结论回答研究问题，不重复表格；政策建议采用"发现 → 判断 → 行动"三段式；建议颗粒度与结果对齐；不做宣传式收束。

**本文的应用**：政策建议改为对本研究具体发现的回应，并保留分品种处理思路（HRI 校正后仅 5/10 品种显著，对应"分品种发布提示"）。

### 2.9 用词与句法

| 规则 | 说明 |
|---|---|
| claim 强度对应证据强度 | 强（证明、表明）只用于确凿证据；中（说明、提示）用于有支持但开放的发现；弱（可能反映、或与……有关）用于推测 |
| 禁止无因果识别的因果动词 | 不得使用"导致""驱动""造成"，除非有识别策略；本文一律用"与……相关""之后收益更低" |
| 禁止"上界"等未经证明的数学表述 | 改用"可能偏乐观""可能被高估""应视为偏乐观的估计" |
| 不显著 ≠ 无差异 | 一律写"未达到统计显著"，并说明置信区间宽度 |
| 市场机会收益 ≠ 农户利润 | 全文统一用"市场价格窗口的相对变化" |
| 概念不重复定义 | 每个边界说明在首次定义与结论收口各一次 |
| 语域 | 引言与结论可读性优先；方法与结果精确性优先；不混用 |

### 2.10 图表与版式

**规范**：表题在表上方、图题在图下方；表格数字右对齐、单位在表头标注；图题自解释；正文引用与图表编号一一对应。

**版式优先级**：**《附件1》官方要求高于参考论文的期刊排版**。参考论文的双栏、小字号一律不照搬。

## 三、本文相对参考论文的差异说明（避免误用范式）

本文与主参照论文的研究类型不同，以下方面**不适用**其范式：

| 差异 | 说明 |
|---|---|
| 研究对象 | 主参照论文研究全国 18 种蔬菜的联动效应；本文研究单一城市十种蔬菜的追高风险环境与决策策略 |
| 数据频度 | 主参照论文用月度数据；本文用日度数据，因而必须处理窗口重叠与自相关，这一点主参照论文未涉及 |
| 方法性质 | 主参照论文以计量识别为主；本文以滚动样本外评价为主，因此"前向验证"的地位比主参照论文更突出 |
| 结论性质 | 本文包含较多否定性结论（预测改进依赖口径、配对不显著），主参照论文无此情况；处理办法是把它们与正向发现并列，并说明其统计学原因 |

## 四、交付前的统一自检清单

- [ ] 引言是否从农业现实问题与福利含义切入，而非技术流程
- [ ] 文献是否按问题组织，每篇是否写明研究了什么
- [ ] 是否说明了为什么需要朴素基线与配对比较
- [ ] 方法设定后是否逐符号解释经济含义
- [ ] 数据适用范围是否在数据章交代
- [ ] 每张表后是否回答"证明了什么/不支持什么/是否与预期一致/其他解释"
- [ ] 机制是否拆成可辨识环节并标明本文能检验哪一环
- [ ] 前向验证的不利结果是否在正文与结论都准确呈现
- [ ] 是否已删除"上界"等未经证明的表述
- [ ] 不显著结果是否保留且未被解释为"无差异"
- [ ] 政策建议是否为"发现→判断→行动"三段式
- [ ] 结论是否回答研究问题而非复述表格
- [ ] 是否仍有验收报告、开发日志或元讨论痕迹
- [ ] 版式是否符合《附件1》而非参考论文期刊样式
