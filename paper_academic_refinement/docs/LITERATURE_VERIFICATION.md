### [13] 蔬菜价格波动的共同影响因子与宏观决定因素

| 项目 | 内容 |
|---|---|
| **著录** | 岳瑞雪, 谭砚文. 蔬菜价格波动的共同影响因子与宏观决定因素[J]. 华南农业大学学报（社会科学版）, 2019, 18(3): 79-91. DOI: 10.7671/j.issn.1672-0202.2019.03.008. |
| **核验方式** | 访问期刊 HTML 页面并下载全文 PDF（13 页），逐页核验作者、单位、基金、摘要与章节结构 |
| **实际研究内容** | 使用均匀间距估计、PANIC 与 VAR 模型，考察 2005 年 1 月至 2018 年 10 月中国 18 种主要蔬菜价格的联动效应、共同影响因子及其宏观决定因素；样本为月度数据 |
| **实际结论** | 蔬菜价格之间的联动效应主要受一个潜在共同影响因子驱动；在该共同因子的宏观决定因素中，货币流动性过剩的影响最强且稳健；生姜、大蒜等耐储存品种表现出更强的异质性行为 |
| **本文可据此陈述** | ①可引其"蔬菜价格存在普遍联动效应（共同因子驱动）"这一发现，说明跨品种比较时须控制共同市场冲击——这正是本文采用**配对设计**的文献依据；②可引其"不同品种行为存在异质性"支持本文按品种分别检验的做法 |
| **本文不可据此陈述** | ❌ 货币流动性、汇率等宏观结论与本文数据无关，不得引作本文结论 |

### [14] 降水对蔬菜价格的冲击效应

| 项目 | 内容 |
|---|---|
| **著录** | 翟志宏, 江民星, 常春英. 降水对蔬菜价格的冲击效应——以广州为例[J]. 资源科学, 2021, 43(2): 304-315. DOI: 10.18402/resci.2021.02.09. |
| **核验方式** | 访问《资源科学》期刊目录页与文章摘要页，核验作者、卷期页码、DOI 与研究设计、主要发现 |
| **实际研究内容** | 构建包含降水因素的蔬菜供需动态模型；基于广州市 2004—2018 年逐日菜心、生菜、豆角零售价格与降水数据，用 VAR、脉冲响应函数与预测方差分解量化冲击 |
| **实际结论** | 逐日过量降水对菜价有正向冲击，冲击效应与需求价格弹性呈反向关系；冲击存在明显时间尺度异质性（日尺度更敏感，三种蔬菜分别在第 16、20、10 天达峰后减弱；月尺度滞后约一个月）；日降水对三种蔬菜价格波动的贡献率约 8.3%、18.4%、1.0% |
| **本文可据此陈述** | ①可引其"蔬菜价格对供给冲击的响应存在品种异质性与时间尺度差异"，支持本文按品种与按窗口分别检验；②可引其"冲击效应存在滞后与衰减"说明为何本文把主结果限定在 30 天窗口 |
| **本文不可据此陈述** | ❌ 该文研究的是降水冲击，不得引作"天气导致价格波动的因果证据"用于本文；本文亦未做天气冲击分析 |

### [15] 预期价格变动对农户生产行为调整的非对称影响

| 项目 | 内容 |
|---|---|
| **著录** | 闵师, 王晓兵, 白军飞, 黄季焜. 预期价格变动对农户生产行为调整的非对称影响——基于西双版纳胶农调查分析[J]. 农业现代化研究, 2017, 38(3): 475-483. DOI: 10.13872/j.1000-0275.2017.0034. |
| **核验方式** | 访问《农业现代化研究》文章页，核验作者、单位、基金、中英文摘要与参考文献列表 |
| **实际研究内容** | 基于适应性预期理论，利用云南省西双版纳自治州 **612 户橡胶种植户**的调查数据，分析价格预期变动下的生产调整行为及异质性 |
| **实际结论** | 预期价格变动幅度越大，农户选择生产调整行为的可能性越高；**预期价格上升时采取调整措施的比例为 53.92%，预期下降时为 29.58%，呈显著非对称性**；调整行为受户主与家庭社会经济特征、种植园条件影响而存在异质性 |
| **本文可据此陈述** | ①可引其"农户对价格上升的反应显著强于对价格下降的反应"，作为本文"追高环境具有现实行为基础"的**实证支撑**；②可引其"行为存在异质性"说明本文按品种分品种检验的必要性；③**必须说明该文研究对象是橡胶种植户、基于问卷调查，而非蔬菜市场** |
| **本文不可据此陈述** | ❌ 不得写成"该文证明了蔬菜种植户存在跟风行为"；❌ 不得把其比例数字（53.92%/29.58%）说成蔬菜市场的结果；❌ 该文为农户层面调查，本文为市场价格层面分析，二者不可互相替代 |

### [16] "没有免费午餐定理"与农业政策研究中的算法选择

| 项目 | 内容 |
|---|---|
| **著录** | 于晓华, 刘爽. "没有免费午餐定理"与农业政策研究中的算法选择：以机器学习预测生猪价格变动为例[J]. 农业经济问题, 2024(5): 20-32. |
| **核验方式** | 访问《农业经济问题》期刊页面，读取该期目录与摘要，核验作者、单位、期号与起始页码 |
| **实际研究内容** | 比较 ARIMA、卷积神经网络（CNN）、循环神经网络（RNN）与长短期记忆网络（LSTM）四种模型对中国生猪价格的预测表现 |
| **实际结论** | 传统 ARIMA 与 LSTM 性能不相上下，二者均明显优于 CNN 与 RNN；从价格极端变化角度 LSTM 略优；结论符合"没有免费午餐定理"——没有算法绝对优于其他算法，研究者应同时采用多种算法；并发现 2018 年前后猪肉价格数据结构发生显著变化，主张数据结构变化时须不断更新模型 |
| **本文可据此陈述** | ①可引其"没有算法绝对占优、应同时比较多种算法"，为本文**把机器学习模型与朴素基线放入同一候选池竞争**提供方法依据；②可引其"数据结构变化时须更新模型"，为本文采用**逐年滚动折**并报告 2026 折表现下降提供依据；③可引其"复杂网络模型未必优于传统模型"呼应本文 ElasticNet 胜出、CatBoost 落选的结果 |
| **本文不可据此陈述** | ❌ 不得写成"已有研究表明 LSTM 适合蔬菜价格预测"；该文研究生猪价格，本文未使用 LSTM |
