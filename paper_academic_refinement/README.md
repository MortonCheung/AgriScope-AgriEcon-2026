## 1. 阅读了哪些成熟论文，学到了什么

**主参照**：岳瑞雪, 谭砚文. 蔬菜价格波动的共同影响因子与宏观决定因素[J]. 华南农业大学学报（社会科学版）, 2019, 18(3): 79-91.（已获取全文 PDF，共 13 页，逐页分析）

提炼出十项可迁移方法（详见 `docs/REFERENCE_PAPER_ANALYSIS.md`），其中对本文影响最大的三项：
- **引言五步链条**：现实关切 → 福利含义 → 成因分类 → 由已有发现推出疑问 → 研究意义；
- **为方法选择单设小节**：用"既有做法的具体局限 + 所选方法如何对应解决"论证，而不是直接列模型；
- **政策建议"发现 → 判断 → 行动"三段式**，建议颗粒度与结果对齐。

**辅助参照**：
- 翟志宏, 江民星, 常春英（2021, 资源科学）——报告冲击效应时同时给出方向、时滞、峰值与强度；
- 安民等（2024, 中国蔬菜）——把"种植意愿"列为蔬菜市场主要风险点，为本文主题提供中文文献依据。

**明确不迁移**：期刊双栏版式、小字号（与《附件1》冲突）；该文的具体模型与宏观结论（与本文数据无关）；任何原文表述。
